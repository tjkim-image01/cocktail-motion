# 2damin — 원화 → Flow 동작 → 프레임 재생 + 독립 눈·입 연기

**2026-10-27 사용자 확정: 앞으로 이 방식으로 2D 애니메이션을 만든다.**
새 2D 캐릭터 애니메이션을 시작할 때 이 문서를 먼저 읽는다.
이름은 사용자가 지정한 **`2damin`** 그대로 사용한다.
기준 작품은 [M013](../../../../project/m013/README.md), 로컬 에디터는
http://127.0.0.1:4344/ 이다. 사용자는 Flow 동작을 “훨씬 좋아졌다”고 평가하고
이 제작 방식을 후속 작업의 기본으로 지정했다. 모든 표정에 대한 별도 완벽 판정으로 확대하지 않는다.

## 기본 제작 순서

1. **캐릭터의 실제 원화를 먼저 사용한다.** 시작·종료 자세를 고르고 원본을 보존한다.
2. **Flow에 시작과 종료 프레임을 둘 다 첨부한다.** 연속 동작과 고정 카메라를 요청한다.
   기본 실행 기준은 Aside **u10/a10**, Omni 1.1 Flash, **360p 생성 → 720p Upscaled 다운로드**,
   10초·결과 1개다. 다음 요청에서 사용자가 바꾸면 그 지시를 따른다.
3. 다운로드 파일을 `ffprobe`로 확인하고 **실제 FPS대로 모든 이미지를 추출**한다.
   브라우저에서는 MP4 대신 이미지 시퀀스를 재생한다. 원본 영상도 보관한다.
4. 프레임마다 얼굴의 눈·입 위치·크기·각도를 등록한다. 눈은 열린 참조를 확보하고,
   원래 영상의 자동 깜빡임을 독립 눈 조절과 분리한다.
5. 눈·속눈썹, **실제 열린 입과 실제 다문 입**을 원화/생성 영상에서 추출한다.
   밑의 피부는 주위 색으로 보충하고 눈썹·머리카락·얼굴 윤곽은 보호한다.
6. **부분 Bézier 경계 모핑 + 추출 픽셀 변형**으로 눈·입만 움직인다.
   몸 그림 전체를 벡터화하거나 전신 모핑으로 바꾸지 않는다.
7. Typecast에서 캐릭터에 맞는 보이스와 대사를 정하고 음성을 생성한다.
   기존 [Typecast 커넥터](../aside/connector/typecast.py)를 먼저 참조한다.
8. 한국어 대사와 실제 음성을 강제 정렬하고, 모음과 양순음(ㅁ·ㅂ·ㅍ),
   WAV의 쉼 구간을 반영한 60Hz 입 모양을 만든다.
9. **몸·음성/입·눈의 시간을 분리**해 에디터에 연결하고 실제 화면으로 검수한다.

M013은 m011 preview `00.jpg`와 `22.jpg` 두 장만 Flow에 넣었다.
23장 전체를 Flow에 넣거나 그 사이를 RIFE로 생성한 결과로 설명하지 않는다.
360p → 720p는 업스케일 다운로드이며 네이티브 720p 생성과 구분한다.
화면비가 원화와 다르면 구도와 비율이 달라지므로 원화에 맞춰 선택·확인한다.

## 반드시 유지하는 시간축

| 대상 | 기준 시간 | 동작 배속/방향의 영향 |
| --- | --- | --- |
| 몸 이미지 | 이미지 재생 시계 | 정방향·역방향·왕복 및 배속 적용 |
| 음성 | `HTMLAudioElement.currentTime` | 항상 정속 1× |
| 입의 대사 연기 | **음성의 현재 시간** | 몸을 멈춰도 계속 말함 |
| 버튼 깜빡임 | `performance.now()` | 몸 정지/역재생과 독립 |

**기본 재생: 정방향↔역방향 왕복, 표시 1×.**
사용자 요청으로 **기존 원본 2배속 움직임을 표시 1배속**으로 정했다.
즉 `실제 이미지 배속 = 표시 배속 × baseSpeed(기본 2)`다.
10초 원본의 한 방향은 표시 1×에서 약 5초이며, 왕복은 약 10초다.
이 값을 음성·입·눈에 곱하지 않는다.

## 원래 열린 입의 그림을 보존한다

M013에서 새로 그린 입은 치아가 가운데를 가로지르고 혀 비율이 달라 사용자가
“안 어울린다”고 지적했다. **이 접근을 다시 기본으로 사용하지 않는다.**

- `mouth-open.png`: 마지막 Flow 프레임 239에서 실제 입을 추출. 끝 원화와 비교.
- `mouth-closed.png`: 첫 프레임 0의 실제 닫힌 입을 추출.
- 위쪽의 얇은 치아, 아래쪽의 넓은 분홍 혀, 어두운 입 안쪽, 원래 먹선을 유지한다.
- 열린 윤곽의 64개 대응점을 같은 cubic Bézier 구조로 연결한다.
- 입의 개폐·너비·둥글기에 맞춰 경계와 내부 원화 픽셀을 함께 변형한다.
- 입을 다문 경우 닫힌 원화의 실제 선을 사용한다.

원화 질감을 담은 래스터 텍스처와 벡터 경계를 함께 쓰는 방식이다.
전체 그림이 순수 SVG이거나 원본 픽셀과 모든 자세에서 완전히 동일하다고 설명하지 않는다.

## 눈 처리

[M007 V8 / anim](../anim/README.md)의 선 소유, 피부 채움, 속눈썹 굵기 보존을 계승한다.
V8 자체에는 말하기가 없으며, 음성·입 기능은 M013에서 추가했다.

- 열린 원본 눈을 사용할 수 있고 조절 값이 기본이면 원본을 그대로 둔다.
- 원래 깜빡이는 프레임에서는 가까운 열린 눈을 현재 눈 위치에 맞춰 등록한다.
- 속눈썹은 굵기를 유지해 내려오고 눈동자 쪽만 아래 눈꺼풀로 접힌다.
- 원래 눈을 지우는 마스크와 새 눈 그림을 분리한다.
- **눈썹·앞머리·관자놀이 경계까지 지우면 안 된다.** 확대해서 끊김을 확인한다.
- 좌우 개별 개폐, 버튼 깜빡임, 자동 깜빡임, 작은 시선 이동을 제공한다.

## 파일 구성과 재사용

```text
2damin.py              init / extract / serve
web/face.js            실제 눈·입 추출 텍스처와 국소 Bézier 변형 런타임
web/player.js          독립 시계, 이미지 캐시, 정/역/왕복, 배속, 대사·표정 조작
web/index.html         로컬 제작용 에디터 템플릿
examples/default.json  새 프로젝트 설정 예시
examples/m013.json     검증 기준 M013의 설정
recipes/m013/          M013 전처리의 소스 기록 (새 캐릭터용 완전 자동 추적기가 아님)
```

새 프로젝트를 준비한다. 같은 파일이 있으면 덮어쓰지 않는다.

```sh
python3 lib/com/jatu/2damin/2damin.py init project/m0xx
python3 lib/com/jatu/2damin/2damin.py extract /path/downloaded.mp4 --project project/m0xx
python3 lib/com/jatu/2damin/2damin.py serve project/m0xx --port 4345
```

`init`은 제작 화면의 뼈대만 만든다. 재생하려면 `manifest.json`, `frames/`,
`face/rig.json` 및 해당 PNG들, 음성과 `audio/lipsync.json`을 준비해야 한다.
`2damin.json`에서 제목·보이스·대사·오디오 파일·기본 배속·재생 모드를 지정한다.
브라우저 API는 `window.anim2d`이며 `jump`, `blink`, `speak`, `stopSpeech`, `face.state`를 제공한다.
Python 디렉터리 이름이 숫자로 시작하므로 위의 **파일 경로 CLI**를 사용한다.

### M013 레시피의 적용 범위

`recipes/m013`은 실제 사용한 소스를 보존하고 프로젝트 루트만 인자로 받게 한 기록이다.
**240장, 720×1280, 파란 눈, 특정 얼굴 위치·크기·피부색, 116×100 눈 아틀라스,
프레임 0/239의 입 참조** 등 캐릭터 전용 값이 있다.
다른 캐릭터에 그대로 실행해 성공한다고 가정하지 않는다. 다음 캐릭터에서는
원화를 보고 검색 범위·색/좌표·참조 프레임·보호 마스크와 런타임의 크기를 맞춘다.

```sh
# 참조용. 기준 M013 자체를 덮어쓰지 말고 별도 작업 폴더에서 실행한다.
PY=project/m013/.venv/bin/python
$PY lib/com/jatu/2damin/recipes/m013/build_face_rig.py /path/work-copy
$PY lib/com/jatu/2damin/recipes/m013/extract_eyes.py /path/work-copy
$PY lib/com/jatu/2damin/recipes/m013/extract_mouth.py /path/work-copy
$PY lib/com/jatu/2damin/recipes/m013/align_speech.py /path/work-copy
```

프레임 추출은 FFmpeg/ffprobe, 얼굴 전처리는 OpenCV/numpy,
한국어 음절 정렬은 stable-ts/faster-whisper small/scipy를 쓴다.
M013 정렬 환경: stable-ts 2.19.1, faster-whisper 1.2.1, torchaudio 2.8.0 / torch 2.8.0.
정렬 레시피의 보이스·WAV 파일명도 새 대사에 맞게 바꾼다.

## Flow와 Typecast에서 확인할 것

[Flow 커넥터](../aside/connector/flow.py)의 기존 `generate_clip()`은 시작 프레임만
자동 첨부하므로 종료 슬롯도 별도로 넣고 **두 이미지의 부착과 순서**를 확인한다.
새 탭을 만든 한 번짜리 Aside REPL은 종료 시 탭이 닫힐 수 있으므로 지속 REPL을 사용한다.
UI 언어와 모델 설정이 계정마다 다를 수 있으므로 현재 화면에서 설정을 확인한다.
720p Upscaled 다운로드는 생성 해상도를 바꾸는 작업과 구분한다.

Typecast에서는 기존 프로젝트 대사를 지우지 않는다. 새 프로젝트를 우선 쓰고,
한도로 재사용할 경우 기존 대사를 보존하고 필요한 문단만 추가한다.
입력 결과와 보이스·감정을 화면에서 확인하고 보이스 출처를 남긴다.
M013은 은솔·기쁨, 25음절·4.75초이며 모델 기반 강제 정렬 경계는 추정값이다.

## 완료 검수와 공유

- 첫·중간·끝에서 얼굴 위치가 따라가고 머리카락과 눈썹이 끊기지 않는지 본다.
- 원래 열린 입과 최대 개방 결과를 나란히 비교한다. 치아·혀 비율이 달라지면 수정한다.
- 몸 정지 중 말하기, 2배속 역재생 중 정속 말하기, 버튼 깜빡임을 확인한다.
- 정/역/왕복, 한 프레임 이동, 음절과 쉼 구간, 눈 재개방을 실제 브라우저에서 확인한다.
- 사용자 승인 전 기존 승인작을 덮어쓰거나 완벽한 완성본으로 기록하지 않는다.

사용자 요청에 따라 **공유용 GitHub Pages에는 감상용 플레이어만**, 제작용 에디터는 로컬에 둔다.
공유본은 실행에 필요한 이미지·눈/입 데이터·음성·정적 코드만 포함하고,
계정 세션·과거 대본 백업·분석 환경·다른 프로젝트를 복사하지 않는다.

기준 감상용 공유본: [M013 공개 플레이어](https://tjkim-image01.github.io/m013-2damin-player/).
허용 목록으로 구성하는 실제 빌드는 [M013 build_pages.py](../../../../project/m013/scripts/build_pages.py)를 참조한다.

눈 경계 보완 사례: M013 화면 왼쪽의 마스카라가 앞머리와 연결돼 피부 hull 밖으로 분류되었다.
연결 덩어리를 통째로 머리카락으로 보호하면 깜빡일 때 속눈썹이 원래 자리에 남는다.
속눈썹 쪽의 선 소유를 국소적으로 지정하고, 연결된 끝선과 흰 안티앨리어싱 테두리까지
같이 지워서 추출 레이어로 옮긴다. 눈썹·머리 외곽은 확대 비교해 보호한다.
