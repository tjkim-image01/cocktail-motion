# 01 — 레퍼런스

출처: https://prompt-motion.com/ror-fly-9950f1 — Rory Flynn, Negroni recipe animation.
미디어: https://media.prompt-motion.com/ror-fly-opus-5-5-rendered-this/video.d79b7c51.mp4

`original.mp4`: 1080×1080, 30fps, 900프레임, 30.000초, 영상 스트림 1개·오디오 0개. 로컬 비교용.

`sec-00.png` … `sec-29.png`는 프레임 번호 0,30,…870을 ffmpeg `select=not(mod(n,30))`로 추출했다. 정확히 정수초를 사용한다. `contact.jpg`·`timeline.jpg`는 전체 관찰용 축소 콘택트시트이며 최초 `fps=1` 샘플링으로 정수초와 약간 다를 수 있다. 모션 기준과 비교 갤러리는 `sec-*` 정확한 캡처만 쓴다.

크림색 정사각 배경, 상단 붉은 제목, 왼쪽 잔(중심 x350, 바닥 y800), 오른쪽 카드(x650,y518), 하단 단계(y927)가 주요 구도다.

원본 사진을 보고 수동으로 동작을 등록했다. 자동 오브젝트 인식·자동 모션 캡처를 했다고 표현하지 않는다.

V2: `deciseconds/frame-000.jpg`~`frame-299.jpg`에 정확한 프레임 0,3,…897의 300장을 추가했다. 이번 상세 관찰은 제목·얼음 0.0~6.0초이며, `analysis-01/`에 시간 표시 관찰표와 원시 윤곽을 보존했다.
