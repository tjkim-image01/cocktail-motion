# 00 — 기획

목표: Prompt Motion의 Negroni recipe animation과 같은 1080×1080, 30초 구도·재료 투입 순서를 Three.js로 재현한다.

방법: 원본 1초 사진에서 물건의 위치와 기울기를 수동 등록한다. 액체는 별도 오브젝트로 그려 수위와 따르기 줄기를 연결한다. 사용자 지정 폴더명은 `tree002`이다.

순서: 타이틀 → 빈 잔 → 큰 얼음 3개 → 진 1 oz → 캄파리 1 oz → 스위트 베르무트 1 oz → 젓기(원본과 같이 압축 표현) → 오렌지 껍질 → CIN CIN.

원본은 음성·음악 스트림이 없는 무음이다. 이번 요청은 이 무음 설명 애니메이션 재현이며 음악에 종속되는 제작은 없다. 새 음악 요청 시 상위 음악 검수 규칙을 적용한다.

완료 기준: 물건별 투명 원화·1초 기준 키·30초 재생·같은 시간 비교·원본 및 제작본 사진 30쌍·단계 문서. 픽셀 단위 동일성이나 사용자 시각적 승인을 자동으로 주장하지 않는다.
