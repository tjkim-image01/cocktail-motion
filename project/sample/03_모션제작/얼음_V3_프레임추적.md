## V3 방법

1. **추적** `scripts/track_ice.py`: 3.9초(빈 잔) 프레임의 먹선을 지운 '새 먹선' 지도에서, 고립된 얼음 1개(4.133초)의 윤곽을 템플릿으로 삼아 회전·배율을 바꿔 가며 매칭. 30fps 모든 프레임에서 x·y·각도·배율을 얻음. 안쪽 회색선까지 먹선으로 포함해 정사각형의 90° 대칭 모호함을 없앰. 결과 `01_레퍼런스/analysis-01/ice-track-30fps.json`.
2. **정리** `scripts/make_ice_v3.py`: 다른 먹선을 가리는 저점수 프레임의 x 이상치만 중앙값으로, 안착 뒤 1px 흔들림은 고정 자세로. 효과선은 남은 짧은 먹선 중 얼음 위쪽 45~75px 거리만 골라 얼음 기준 상대좌표로 저장. 결과 `intro-motion-v3.json`.
3. **재생** `web/intro.js`: 기록된 프레임 값을 그대로 쓰고 프레임 사이만 선형 보간. 효과선은 원본 프레임 단위로 유지. 얼음 그림은 원본 정렬 확대본에서 잰 치수로 벡터를 그린 CanvasTexture(71px 둥근 사각형, 반경 13, 먹선 3.1px, 안쪽 선 1.5px).
4. **6초 이후**: 추적된 안착 자세에 후반 트랙(`motion.json`)의 6초 대비 변화량만 더함.
5. **검증**: 같은 추적기로 V3 MP4를 다시 추적해 원본과 비교 → 공통 화면 오프셋(0.8px, 1.9px)을 그림 보정값 `iceArtOffset`으로 넣고 재렌더.
