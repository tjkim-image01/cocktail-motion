# 03 — 사진 기준 동작, V2

최신 분석은 [0.1초 동작분석](0.1초_동작분석.md)이다. `intro-motion-v2.json`과 `web/intro.js`가 제목 7글자의 독립 팝, 2.6~3.3초 상단 이동, 세 얼음의 낙하·회전·반동·안착을 소유한다.

`python3 scripts/make_intro_study.py`로 상세 설정을 재생성한다. 관찰 위치와 추정 충돌 시간을 구분하며, 후반 동작은 아래 기존 `motion.json`을 사용한다.


`motion.json`: 물건별 `[time, x, y, clockwise_rotation_degrees, opacity]`. 화면 좌표는 1080×1080, 좌상단 원점.

원본 `sec-00`부터 `sec-29`까지를 보고 수동으로 키를 등록하고, 모든 정수초 키를 저장했다. 떨어지는 얼음, 병 진입과 복귀, 따르기 시작·종료에는 추가 소수초 키를 사용한다. 사진 자체를 재생하는 것이 아니라 사진에 맞춘 키 사이에서 독립된 물건을 보간한다.

투명/붉은 액체 트랙의 y는 물체 중심이 아닌 **수면 위치**다. 바닥 y755는 고정한다. 얼음은 액체와 따로 움직이고, 젓기 구간은 스푼 위치와 얼음 위치를 같이 바꾼다. 스프링이나 임의 부유로 원본에 없는 큰 동작을 추가하지 않는다.

키 재생성: `python3 scripts/make_motion.py` (프로젝트 루트에서). 사용자가 정한 이전의 '개별 물건 → 1초 사진 → 사진을 따라 이동' 흐름을 따른다.

오차: 사진 기반 눈대중 등록으로 픽셀 계측이나 자동 추적은 아니다. 원본과 0.x초 단위의 전환감 차이가 남을 수 있다.
