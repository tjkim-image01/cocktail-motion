2026-10-29. 사용자 요청: V3 얼음 결과에 “완전 좋아”라고 한 뒤 “전체를 똑같이 해서 만들어줘, 소리도 만들어줘”라고 했다. 소리 범위는 **효과음만**으로 정했다(사용자 선택). 배경음악은 쓰지 않았다.
진행 중 반영한 사용자 지적:
- 얼음 색이 주변 액체색에 맞게 변해야 한다.
- 물줄기를 더 굵게, 액체가 얼음에 닿을 때의 기포를 살려야 한다.

- 컵이 등장할 때 선이 그려진다.

### 측정에서 드러난 원본 규칙 (V3까지 틀렸던 것)

- **카드 전환:**
  - 이전 카드는 즉시 사라진다. N 프레임에는 새 큰 글자만 0.902배·+4.6°로 나온다.
  - N+1부터 카드가 같은 변환으로 돌아온다. 이 변환은 `easeOutBack`으로 12.5프레임 동안 1배·0°로 돌아간다.
  - 분홍 그림자는 처음부터 불투명하고, 카드 본체만 투명도가 0.58 → 1로 오른다.
- **컵 등장:** 왼쪽 옆선(85–96) → 오른쪽 옆선(89–100) → 입구 앞쪽 왼쪽 → 입구 뒤쪽 → 바닥 곡선(오른쪽→왼쪽) → 안쪽 바닥선 → 입구 앞쪽 오른쪽 순으로 그려진다. 이어서 채움(100–114)과 하이라이트(104–114)가 생긴다.
- **액체:**
  - 표면은 타원이고, 앞뒤 수면선 사이의 띠가 더 밝다.
  - 바닥은 평평하고 진한 경계선이 있으며(y 756), 그 아래가 두꺼운 유리 받침이다.
  - 진은 228–285, 캄파리는 381–440, 베르무트는 530–585 프레임에 수위가 61.5px씩 오른다.
- **잠긴 얼음:**
  - 색은 얼음색과 액체색을 0.62 비율로 섞은 값이다. 젓는 동안(631–733)은 0.83이다.
  - 수면의 뒤쪽 수면선 아래가 모두 물든다.
  - 외곽선은 액체 쪽으로 흐려지고, 왼쪽 아래 가장자리에 흰 빛 테두리가 생긴다.
- **젓기:**
  - 스푼은 631에 위에서 떨어져 들어온다.
  - 0.8초(24프레임) 주기로 −2.5°~+11.1°를 오간다. 숟가락 끝은 잔 안에서 약 110px 폭으로 움직인다.
  - 얼음 3개는 서로 엇갈린 원을 그리며 ±15px·±8°로 움직인다.
  - 722부터 빠져나간다.
- **술병:**
  - 왼쪽 밖에서 들어온다(189–202). 약 116°까지 기울이고(203–217), 114.6°~117.6°를 0.89초 주기로 흔들며 따른다.
  - 다시 세운 뒤(296–308) 왼쪽으로 빠진다(311–317).
  - 색은 먹선보다 약 2~3px 왼쪽으로 어긋나게 칠해져 있다.
- **줄기:**
  - 굵기 12.5px로 일정하다. 양쪽 먹선 1.5~2.6px, 안쪽 하이라이트 선이 있다.
  - 입구에서 가속하며 자라 7프레임 만에 수면에 닿는다.
  - 끝날 때는 입구에서 떨어져 꼬리가 아래로 떨어진다.
- **기포:** 진은 회색 고리, 캄파리·베르무트는 진한 붉은 점이다. 점은 매 프레임 새로 그려진다.
- **껍질:**
  - 739에 0.5배에서 1.1배로 튀어나온다.
  - 751–767에 가로로 눌리며 비틀리고, 754–771에 향 방울이 떨어진다.
  - 잔 테두리에 떨어진 뒤 오른쪽으로 미끄러져 쉰다.
- **마무리:** 빛살 7개가 814–821에 차례로 나타난다. 822–848에 잔이 1.034배로 커지고, 눈금도 함께 움직인다.

## 플레이어 구성 (`04_장면조립/web/`)

- `scene.js`: 2D 캔버스 한 장에 원본의 앞뒤 순서대로 그리고, Three.js 평면에 올린 뒤 `boil.js` 후처리(선 떨림)를 거친다.
  - 순서: 제목 → 잔(뒤) → 액체 → 얼음 → 잔 선 → 스푼 → 빛살·껍질 → 얼음 충돌선 → 병·줄기 → 눈금 → 카드 → 타임라인
  - V3까지 쓰던 Imagegen 원화(잔·병·스푼·껍질·액체 PNG)는 V4 화면에서 쓰지 않는다. 전부 측정 치수의 벡터 그림이다.
- `world.js`: 잔·액체·얼음·스푼·껍질·기포·빛살 + 컵 등장
- `bottles.js`: 병·줄기·물방울
- `ui.js`: 카드·큰 글자·막대·카운터·타임라인·눈금
- `intro.js`: 제목(V3 그대로) + 부제 등장(101–111, 6px 상승)
- 효과음은 `05_음악동기화/tree002-v4-sfx.wav`를 애니메이션과 같은 시계로 재생한다.

## 효과음 (`05_음악동기화/`)

- `scripts/v4/make_sfx_events.py`가 위 측정 데이터에서 **사건 프레임만 읽어** 82개 큐를 만든다. 결과는 `sfx-v4-events.json`이고, 큐마다 근거를 `note`에 적었다.
  - 제목 글자 등장, 제목 이동, 컵 선 7개
  - 카드 입장 7회, 얼음 카운터, 타임라인 완료, 눈금 도달
  - 얼음 충돌: 추적에서 속도가 뒤집히는 프레임
  - 병 들어옴·나감, 줄기 시작~끝, 숟가락 방향 전환, 껍질 비틀기·향 뿌리기, 건배·빛살
- `scripts/v4/sfx.py`가 모든 소리를 직접 합성한다(샘플 음원 없음, 시드 고정). 결과는 `tree002-v4-sfx.wav`이고 −18.3 LUFS, 최대 −1 dBTP다.
- 배경음악은 없다. 이 영상에 음악을 넣으려면 프로젝트의 음악 검수 규칙(후보 청취 → 선택)을 따른다.

## 남은 차이

- 제목과 카드 글자 서체: 원본 서체를 확인하지 못했다.
- 선 떨림: 크기와 주기는 같지만 무작위 모양은 다르다.
- 껍질 모양: 원본 확대 사진에서 중심선을 손으로 따라 그렸다.
- 젓기 중 수면 물결: 원본 프레임을 보고 맞춘 근사치다(측정값 아님).
- 효과음: 합성 결과를 귀로 검수하지 않았다(레벨만 확인).
