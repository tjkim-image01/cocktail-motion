# V2 — 0.1초 동작 관찰과 수정

2026-10-29. 사용자 평가: V1은 원본과 차이가 너무 크며, **한 글자씩 통통 튀는 제목**과 **동적인 얼음 낙하**를 다시 만들라는 요청.

## 관찰 방법

- 원본은 30fps. 프레임 0, 3, 6, …, 897을 추출해 `01_레퍼런스/deciseconds/frame-000.jpg`~`frame-299.jpg` **300장**을 저장했다. 0.0~29.9초, 간격 0.1초.
- 이번 상세 분석 범위는 요청한 제목과 얼음이 나오는 **0.0~6.0초**다. `analysis-01/sheet-00`~`sheet-06`에 시간 표시가 붙은 관찰표를 남겼다.
- 제목의 붉은 화소 경계, 빈 잔과 달라진 윤곽을 보조 자료로 추출하고 사진과 대조했다. JPEG와 손그림 선 때문에 하나의 글자가 여러 윤곽으로 나뉜다. 원시 윤곽을 '정확한 글자 인식 결과'로 취급하지 않는다.
- 아래 위치는 1080px 화면에서의 근사치다. 소수 셋째 자리 충돌 시간은 사진 사이의 움직임을 연결하기 위한 **제작용 추정치**이며 원본 코드나 물리 계측 결과가 아니다.

## 1. 제목 — 글자가 자기 자리에서 팝

관찰된 핵심은 '타이핑된 문자열을 매번 가운데 정렬'하는 것이 아니다. 뒤 글자가 생겨도 앞 글자는 그 자리를 유지한다. 각 글자는 밑변 근처를 기준으로 작게 시작해 정상 크기를 넘고, 기울기와 크기가 줄어들며 안착한다.

| 원본 시간 | 관찰 |
| --- | --- |
| 0.0~0.1 | 빈 화면 |
| 0.2 | N이 작은 크기로 나타남. 높이 약 59px |
| 0.3 | N이 정상 크기 가까이 커짐 |
| 0.4 | N은 약간 커진 상태, E가 성장 중 |
| 0.5 | E가 커진 상태, G가 작은 크기로 등장 |
| 0.6 | G가 커지고 N·E는 안정됨 |

| 0.8 | R이 크게 튀고 O가 작게 등장 |

| 1.0 | 두 번째 N이 성장 |

V2 적용:

- 글자 7개에 고정된 자리와 독립된 등장 시계를 부여했다. 제작용 시작 시간은 약 0.14 / 0.30 / 0.44 / 0.60 / 0.75 / 0.90 / 1.05초.
- 작은 크기 → 약 114% → 113% → 103% → 100%로 안착. 글자마다 작은 회전 반응을 더했다.
- 제목 전체의 중앙 정렬을 글자 추가 때마다 다시 계산하지 않는다.
- 상단 이동은 2.6~3.3초 관찰 위치를 통과하는 단일 제목 그룹 이동이다. 이전처럼 큰 제목과 작은 제목을 겹쳐 페이드하지 않는다.
- 제목 서체를 원본의 불규칙한 굵은 글자에 더 가까운 Luckiest Guy로 변경하고 각 글자의 폭과 높이를 따로 맞췄다. 원본과 동일한 서체임을 확인한 것은 아니다.

## 2. 얼음 — 빠른 낙하, 큰 반동, 작은 반동

> **V3에서 대체됨.** 아래 0.1초 관찰과 V2 적용은 원본과 차이가 컸다(그림·회전·효과선·충돌 높이). 현재 얼음은 [30fps 프레임 추적 V3](얼음_V3_프레임추적.md)를 쓴다.

V2 적용:

- 1번 x≈296(왼쪽 아래), 2번 x≈402(오른쪽 아래), 3번 x≈350(가운데 위)를 독립 궤적으로 움직인다.

- 얼음 구간에 술병이 미리 비치던 V1 오류도 수정했다. 진 병의 첫 진입은 약 6.3초로 미뤘다.

## 비교와 산출

- 비교 페이지에서 **−0.1s / +0.1s**, **글자 등장 반복**, **얼음 반복**, 0.25×·0.5× 속도를 제공한다.
- 원본 300장과 V2 300장을 같은 시간으로 짝지었다. 기본은 제목 사진, 선택 메뉴에서 얼음 또는 전체 300쌍을 본다.
- 재생 결과를 1080×1080·30fps·900프레임·30초 MP4로 내보냈다. 앞부분 6초와 원본/제작본 좌우 비교 6초도 별도 저장한다.
- 제작 원본: `intro-motion-v2.json`, `web/intro.js`, `web/scene.js`. V1 소스는 `06_출력검수/baseline-v1/`에 보존했다.

남은 차이: 물건 원화의 선·디테일, 잔의 형태, 카드 등장 연출과 후반의 다른 오브젝트 동작은 원본과 차이가 남는다. 이번 수정의 상세 분석·재제작 범위는 제목과 얼음이며, 전체 영상이 원본과 같아졌다고 평가하지 않는다.
