# 05 — 음악 / 시간

이번 원본과 제작본은 모두 **무음**. ffprobe로 원본 오디오 스트림이 0개인 것을 확인했다. 음원 후보를 도입하지 않았으며 새 음악 승인도 가정하지 않는다. 사용자 요청은 무음 원본 재현이므로 음악에 종속되는 제작은 없다.

30초 공통 시계로 단계와 오브젝트를 동기화한다. 음악을 추가하자는 요청이 오면 `../../음악_검수규칙.md`의 후보 청취·사용자 선택 절차를 먼저 적용한다.

## V4 효과음 (2026-10-29)

사용자가 “소리도 만들어줘” 요청 뒤 범위 질문에서 **효과음만**을 골랐다. 배경음악은 없으므로 음악 검수 규칙의 대상(음악 후보)은 아니다.

- `sfx-v4-events.json`: 측정된 사건 프레임에서 자동 생성한 큐 82개. 근거는 `note`에 있다. 생성 스크립트는 `scripts/v4/make_sfx_events.py`.
- `tree002-v4-sfx.wav`: `scripts/v4/sfx.py`가 직접 합성했다. 48kHz 스테레오, −18.3 LUFS, 최대 −1 dBTP, 샘플 음원은 쓰지 않았다.
- 플레이어는 이 WAV를 애니메이션과 같은 시계로 재생한다. MP4에는 AAC로 합쳤다.
- 귀로 하는 청취 검수는 사용자 평가 전이다.
