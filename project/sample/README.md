**최신 V4:** 사용자 요청(“전체를 똑같이, 소리도”)으로 30초 전체를 원본 **매 프레임 측정값**으로 다시 만들고 **합성 효과음**(배경음악 없음, 사용자 선택)을 붙였다. 측정 대상: 카드 전환, 컵 등장(선 그리기), 액체, 얼음, 술병, 줄기, 젓기, 껍질, 빛살, 선 떨림. 원본과의 화면 평균 차이는 6.01 → 3.40이다. [V4 기록](03_모션제작/V4_전체_프레임측정.md) · 영상 `06_출력검수/render/tree002-v4-30s.mp4`, 비교 `tree002-v4-compare-30s.mp4`. V3는 `06_출력검수/baseline-v3/`에 보존. 사용자 평가 전.

**이전 V3:** 사용자 지적(“얼음 넣는 부분이 이상하고 모션도 그렇다”)으로 얼음을 **원본 30fps 전 프레임 추적값**으로 다시 만들었다. 얼음 그림을 원본 치수의 먹선 벡터로 바꾸고, 회전·충돌 높이·효과선·등장/안착 프레임·그리기 순서를 원본 측정값에 맞췄다. 위치 오차 중앙값 0.4px(V2 2.0px, 최대 46px→6.3px). [V3 기록](03_모션제작/얼음_V3_프레임추적.md) · [재사용 기법](../wiki/레퍼런스_동작_프레임추적_기법.md). 영상 `06_출력검수/render/tree002-v3-30s.mp4`, 얼음 비교 `tree002-v3-compare-ice-slow.mp4`. V2는 `06_출력검수/baseline-v2/`에 보존. 사용자 평가 전.

**이전 V2:** 사용자 지적으로 제목과 얼음을 0.1초 사진으로 다시 분석했다. [특징 정리](03_모션제작/0.1초_동작분석.md). 제목은 글자별 팝 후 상단 이동, 얼음은 화면 위에서 낙하·큰 반동·작은 반동·안착한다. 물건 9종은 기존 Imagegen 원화를 재사용한다.

V1의 흐름: 원본 30초 무음 영상 → 정확히 0, 1, … 29초 캡처 → 물건별 Imagegen 원화 → 사진에 맞춘 위치·각도·수위 키 → Three.js 실시간 재생 → 동일 시점 비교. 생성 이미지의 형태와 서체는 원본과 차이가 남는 **재현 시안**이다. 사용자 만족 판정 전이다.

비교 페이지는 원본과 제작본의 공통 재생·정지·시간 이동·프레임 이동·속도·반복을 제공한다. 하단 사진의 왼쪽은 원본, 오른쪽은 제작본이다. 생성 물건 원형도 펼쳐 볼 수 있다.

영상 파일을 제작본에 대신 재생하지 않는다. 생성 원화를 독립 Three.js 평면에 놓고 변환한다. 제목·설명 카드·진행선·따르는 줄기는 CanvasTexture를 사용하며, 맑은 액체와 붉은 액체 PNG는 잔 안에서 아래쪽을 고정하고 수위에 맞춰 변형한다. 물리 유체 시뮬레이션이나 자동 영상 추적은 아니다.

원본 MP4는 출처를 표시한 로컬 비교용으로만 보관한다. 공개 배포는 진행하지 않았다. 기존 three001은 수정하지 않았다.
