# Cocktail 제작 위키

네그로니 작업에서 확인한 방법을 다른 칵테일·음료·요리의 손그림 모션그래픽에 응용하기 위한 문서다.

1. [같은 스타일 제작법](같은_스타일_제작법.md) — 실제 V4 구조, 그림·동작·시간·소리 규칙
2. [레퍼런스 동작 프레임 추적 기법](레퍼런스_동작_프레임추적_기법.md) — 기존 기법 문서 복사, 링크 이관
3. [새 작품 시작](새_작품_시작.md) — 샘플 복사와 교체할 파일
4. [샘플 코드 지도](샘플_코드_지도.md) — 코드·데이터·산출물 대응
5. [진행 기록](진행_기록.md) — V1~V4의 변화와 이관 기록
6. [음악 검수 규칙 원본](음악_검수규칙_원본.md) — 기존 프로젝트의 규칙 보관

실행 가능한 기준은 [sample](../sample/README.md)이며, [V4 측정 기록](../sample/03_모션제작/V4_전체_프레임측정.md)과 [0.1초 관찰 기록](../sample/03_모션제작/0.1초_동작분석.md)을 함께 본다.

**기본 작업 순서:** 개별 물건 준비 → 원본 시간별 관찰 → 빠른 동작의 매 프레임 측정 → 동작 데이터 → Three.js 재생 → 같은 시점 원본 비교 → 영상 출력. 원화 형태·선 굵기·가림 순서도 동작만큼 중요하다.
