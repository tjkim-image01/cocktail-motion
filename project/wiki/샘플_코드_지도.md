# 샘플 코드 지도

모든 경로는 `project/sample` 기준이다. 파일명에 tree002·V3가 남아 있어도 현재 V4에서 읽는 파일일 수 있다. 초기 방식과 현재 런타임을 구분해서 본다.

## 실행 경로

`server.mjs` → `04_장면조립/web/compare.html` → `app.js` → `scene.js` → 그림 모듈·JSON·로컬 Three.js. `/index.html`은 제작본 단독 페이지다. 서버 루트는 실행 명령의 현재 디렉터리가 아니라 `server.mjs`가 있는 폴더로 결정된다.

| 파일 | 역할 |
| --- | --- |
| `04_장면조립/web/app.js` | 재생 시계, 원본/효과음 동기화, 배속·반복·탐색, 캡처·출력 API |
| `04_장면조립/web/scene.js` | 1080 캔버스 조립, Three.js 평면, 후처리 |
| `04_장면조립/web/intro.js` | 글자별 제목 등장·이동, 얼음 추적 보간·충돌선 |
| `04_장면조립/web/world.js` | 컵 draw-on, 액체·수면, 잠긴 얼음, 스푼·껍질·빛살 |
| `04_장면조립/web/bottles.js` | 병 그림·기울기, 줄기·물방울 |
| `04_장면조립/web/ui.js` | 카드·큰 글자·카운터·눈금·타임라인 |
| `04_장면조립/web/boil.js` | 8Hz 선 떨림 후처리 |
| `04_장면조립/vendor/` | 로컬 Three.js·서체·라이선스 |

## 자료와 출력

- 원본: `01_레퍼런스/original.mp4`, 출처·캡처는 해당 단계 README.
- 관찰용 원본 사진: `01_레퍼런스/deciseconds/frame-000.jpg`~`299.jpg`.
- 제작본 사진: `06_출력검수/qa/deciseconds/`의 같은 번호. 번호÷10이 초다.
- 개별 생성 원화와 프롬프트: `02_아이콘제작/`. V4 장면에서는 사용하지 않지만 비교 페이지의 원화 보드와 초기 버전에 필요하다.
- 완성 영상: `06_출력검수/render/tree002-v4-30s.mp4`.
- 비교 영상: 같은 폴더의 `tree002-v4-compare-30s.mp4`, 젓기 슬로 비교.
- 버전 보존: `06_출력검수/baseline-v1`, `baseline-v2`, `baseline-v3`.
- 전체 비교 지표: `scripts/v4/compare_frames.py`와 `01_레퍼런스/analysis-v4/compare-v3-v4.json`.

현재 영상은 복사한 완성 파일이다. 효과음을 재합성하면 기존 최종 WAV의 음량 정규화까지 자동 재현되는지 별도로 확인한다. 캡처/출력 API는 저장된 파일을 갱신하므로 기준 sample에서는 목적 없이 실행하지 않는다.
