# 음악은 먼저 듣고, 사용자가 결정한 뒤 제작한다

2026-10-28 사용자 요청으로 확정. `project-threejs`의 모든 작품에 적용한다.

> 음악 후보 준비 → 사용자가 직접 청취·검수 → 사용 여부와 진행 여부 결정 → 승인된 곡으로 영상 제작.

## 진행 순서

1. **후보 준비:** 새 곡 또는 이용 조건을 확인할 수 있는 음원을 준비한다. 후보마다 파일·버전·길이·출처·제작 방식·예정 구간을 기록한다.
2. **들려드리기:** 재생 가능한 음원 파일이나 링크를 제공한다. 곡 설명이나 BPM 숫자만으로 검수를 대신하지 않는다. 발췌본이면 원곡과 발췌 구간을 함께 표시한다.
3. **사용자 결정:** `이 곡으로 진행`, `수정 후 다시 듣기`, `다른 후보`, `보류/중단` 중 사용자가 결정한다. 같은 뜻의 자연어 답변도 기록한다.
4. **결정 반영:** 승인된 파일과 구간을 고정한 뒤 본격적인 아이콘·모션·장면 제작, 음악 동기화와 최종 합성을 진행한다. 미승인·수정·보류 상태에서는 음악에 종속되는 후속 제작으로 넘어가지 않는다.
5. **변경 시 재검수:** 곡 교체나 구조·템포·핵심 편곡 등 청취 인상을 바꾸는 수정은 새 버전으로 들려드린다. 단순 포맷 변환도 원본과의 연결은 기록한다.

승인 전에는 기획 문서·레퍼런스 조사·음악 후보 준비를 할 수 있다. 폴더 번호 `05_음악동기화`는 후반의 동기화 작업을 뜻하며, **곡 선택과 청취 승인은 기획 단계에서 먼저** 받는다. 자동 승인이나 답변 기한은 없다.

이번에 사용자가 “맞아 비슷한 느낌으로 음악을 만들어줘.. 움직임도 바꿔주고”라고 짧은 음악·동작 묶음 수정을 직접 요청했다. 이 요청 범위에서 **약 10초의 공동 검수 시안**을 제작한다. 이는 새 음악의 최종 승인이나 곡 전체 본편 제작 승인으로 해석하지 않는다. 기존 N02 승인은 v1 기록으로 보존하고 N03 편집본은 별도로 판단한다.

## 검수 기록

각 작품의 `05_음악동기화/음악검수.md`와 `음악승인.json`에 정확한 후보 파일·버전, 청취 제공 여부, 사용자 결정과 날짜, 선택한 구간을 적는다. 사용자가 명시적으로 선택하기 전에는 선택 파일을 비워 둔다.

## 「MAKE IT FUNKY NOW」를 참고하는 범위

- 사용자는 원곡의 느낌을 좋아한다. 새 곡의 방향은 탄력 있는 펑크 베이스, 명확한 드럼 어택, 짧은 브라스, 익살스러운 악센트처럼 일반적인 음악적 특징으로 기술한다.
- 원곡 음원은 사용 허락이 확인된 것으로 간주하지 않는다. 공개 영상에 넣을 때는 해당 사용에 필요한 허락·라이선스를 확인해야 한다. [YouTube 음악 사용 안내](https://support.google.com/youtube/answer/6364458?hl=ko)
- 직접 다시 연주하거나 재녹음해도 원곡 작곡의 권리까지 없어지는 것은 아니다. 음악저작권과 실연·음반제작자의 권리는 구분한다. [한국음악저작권협회 안내](https://www.komca.or.kr/CTLJSP?EVENTID=info_05_list&MENUID=1000005023005&SYSID=PATHFINDER&S_PAGENUMBER=1&S_ROWS=100&S_TTCON=)
- 이번에는 그 분위기를 참고한 **독립된 새 곡을 후보로 준비하는 방향**으로 한다. 원곡 멜로디·특징적인 리프·샘플을 그대로 옮기는 방식으로 진행하지 않는다.
- AI로 만들더라도 생성 서비스·계정의 영상 사용 및 상업 이용 조건을 확인한다. 생성했다는 사실만으로 이용 조건 확인을 대신하지 않는다.
